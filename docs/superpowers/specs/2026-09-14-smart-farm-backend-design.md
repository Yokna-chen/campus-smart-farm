# 校园智慧农场后端设计

## 目标

交付一个 Java 8 / Spring Boot 2.7 后端 MVP，向 React 前端提供认证、总览、光伏、灌溉、气象、环境、监控和审计 API。FusionSolar 与 Hydrawise 使用可替换的接入适配器，当前实现提供演示适配器，不保存或暴露真实凭据。

## 架构

应用按领域划分为 auth、device、integration、irrigation、overview、audit 和 api 层。领域服务依赖接口而非第三方 SDK，integration 层负责外部调用、同步、重试和同步日志；api 层只负责 HTTP DTO、鉴权和错误映射。数据通过 Spring Data JPA 持久化，默认 H2，生产可通过环境变量切换 MySQL。

## 核心流程

1. 登录接口校验用户密码，签发后端内存令牌；后续请求通过 `Authorization: Bearer` 识别用户和角色。
2. 总览服务读取各领域最新快照，按照数据源时间计算 freshness，过期数据标记为延迟。
3. 定时同步服务调用设备接入端口，将外部快照转换为本地实体，并记录成功、失败和最后同步时间。
4. 灌溉控制服务在发指令前校验角色、分区时段、最大时长和当前运行冲突；指令与后续状态确认均写入运行记录和审计日志。

## 安全与错误处理

- 第三方凭据只通过配置占位符或环境变量读取，日志禁止输出令牌和密钥。
- 密码使用 BCrypt 哈希。
- 未认证返回 401，无权限返回 403，业务规则冲突返回 409，参数错误返回 400。
- 外部调用采用有限重试；连续失败只产生同步错误状态，不无限重试，也不把旧数据标记为实时。

## 验收重点

- 角色登录与越权拦截。
- `/api/overview` 返回光伏、灌溉和设备延迟标记。
- 灌溉启动、停止、暂停具备时长和权限校验并可审计。
- H2 测试上下文可启动，Maven 测试和打包通过。
